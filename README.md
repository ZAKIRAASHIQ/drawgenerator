# Kumite Draw Generator

Installable web app (PWA) for karate kumite knockout draws.

- Bracket size = next of 4, 8, 16, 32, 64 · BYEs = bracket − players · total bouts = players − 1
- Seeds at opposite ends, BYEs to top seeds
- Same-club players kept apart as long as possible
- Bout numbers, AKA (top) / AO (bottom), order-of-bouts list, club check
- Works offline after first open; share or print the bout list

Hosted with GitHub Pages: open the site on your phone and choose **Add to Home Screen**.
